# 1. 登录日志服务器

# 2. 创建/data/stat目录
```bash
mkdir /data/stat
```

# 3. 将解压缩的文件上传到 /data/stat/ 目录下

文件结构类似如下
![alt text](image.png)

# 4. 修改Stat_SaveNetLog_worldship.xml中的配置

```xml
<?xml version="1.0" encoding="gb2312" ?> 
<cfg>
        <logstat CreateLogHead="LogStat" LogDir="/data/stat/Log" StatAddr="10.10.0.21" StatPort="33000"/>
</cfg>
```
把 ip 修改为本机内网

# 5. 运行服务

```bash
cd /data/stat
./RunStat_SaveNet
```

# 6. 查看运行日志

```bash
cd /data/stat
tail -f Stat_SaveNetLog.log
```
